# Mirna Birthday Card

An interactive static HTML birthday card made for GitHub Pages. The first page
is a simple Flappy-style game: reach score 10 to unlock the birthday wish page.

## Open locally

Open `index.html` in a browser, or run a tiny local server:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload or push all files in this folder.
3. In the repository, go to **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Choose the `main` branch and `/root`, then save.
6. GitHub will publish the card at the Pages URL it shows there.
